# HomeRadar Mallorca

Headless .NET 10 service that watches low-competition property sources in Mallorca (servicers, bank portals, local
agencies), records every change of every listing, and tells its owner what they can actually afford.

- Architecture and decisions: `docs/adr/`
- Source inventory: `docs/sources/README.md`
- Tax rules (Illes Balears, verified): `docs/fiscalidad-baleares.md`
- Infrastructure costs: `docs/infra/`
- API contract draft: `docs/api/openapi.v1.draft.yaml`
- Phase summaries: `docs/fase-*-resumen.md`

Phase 0 (research) is complete. Phase 1 (core ingestion + alerts) starts next.
